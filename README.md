# ⚡ AuditInvoice - B2B AI Invoice & Accounting Document Auditor

> نظام مؤسسي ذكي لتدقيق وأرشفة الفواتير والمستندات المحاسبية بالذكاء الاصطناعي واكتشاف الأخطاء الحسابية والضريبية.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **الفحص والتدقيق الآلي (Smart OCR & Document Audit):**
   - استخراج بيانات الفواتير بدقة (اسم المورد، الرقم الضريبي، رقم الفاتورة، البنود، التواريخ، الإجمالي).
   - تدقيق فوري للعمليات الحسابية واكتشاف أي فروقات في المجاميع.
   - التحقق من دقة حساب ضريبة القيمة المضافة (15% السعودية، 5% الإمارات، 14% مصر).
   - التحقق من هيكل الرقم الضريبي الموحد (15 رقماً يبدأ وينتهي بـ 3).
   - كشف الفواتير المكررة لمنع دفع نفس الفاتورة مرتين.

2. **عارض الفحص التفاعلي (Split Inspector):**
   - معاينة المستند بجانب حقول التعديل المباشرة.
   - إعادة التدقيق الحسابي اللحظي مع إظهار شارات التنبيه (سليم / تنبيه / اشتباه).
   - زر نسخ القيد المحاسبي المزدوج (Debit / Credit) بضغطة واحدة.

3. **لوحة المؤشرات والتقارير (Analytics & Reports):**
   - إحصائيات فورية للمبالغ والضرائب المستردة حسب العملات (SAR, AED, EGP, USD, EUR).
   - تصدير كامل إلى Excel (CSV) بترميز UTF-8 لدعم اللغة العربية 100%.

4. **دليل وخطة تسويق وبيع التطبيق مدمجة داخل الواجهة:**
   - باقات تسعير جاهزة للبيع بنظام SaaS.
   - حاسبة عائد الاستثمار (ROI Calculator) لإقناع الشركات بتوفير التكاليف.
   - خطة بيع الكود بالكامل والاستحواذ عبر Acquire.com و Flippa.

---

## 🚀 طريقة التشغيل السريع (1-Click Run on Windows)

1. انقر مرتين على ملف:
   `تشغيل_التطبيق.bat` أو `start.bat`
2. سيفتح التطبيق تلقائياً في المتصفح على:
   `http://localhost:3000`
